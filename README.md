# Marketing Funnel & Conversion Performance Analysis

## Project Overview
This project analyzes marketing funnel performance to identify conversion trends, channel effectiveness, and customer drop-off points.

## Tools Used
- Python
- Pandas
- Streamlit
- Matplotlib

## Features
- Funnel analysis
- Conversion rate calculation
- KPI metrics
- Channel performance analysis
- Interactive dashboard
